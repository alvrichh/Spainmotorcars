# SpainMotors Cars

Escaparate visual premium de coches. Stack nativo: HTML + SCSS + JavaScript + Webpack.

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Estructura

```text
src/
  assets/images/        # logo, composiciones editoriales y coches mock
  scripts/
    components/         # render de bloques
    data/               # mock data local
    modules/            # interacciones suaves
  styles/
    base/               # variables, reset, tipografia
    components/         # header, hero, about, inventory, footer
    pages/              # ajustes de pagina
  index.html
  index.js
webpack.config.js
vercel.json
```

## Deploy

Proyecto listo para Vercel con salida en `dist/`.
